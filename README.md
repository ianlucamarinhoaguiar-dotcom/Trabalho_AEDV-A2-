O presente trabalho propõe analisar as sinopses estatísticas da Educação Básica disponibilizadas pelo INEP
ao longo dos anos, bem como o Censo Demográfico de 2022. As visualizações e outras *views* obtidas a partir das análises
feitas.

Os integrantes do projeto são Ian Luca, João Pedro e Davi Ribeiro, como está referido no arquivo unificado das perguntas levantadas desde
a etapa inicial do projeto.
